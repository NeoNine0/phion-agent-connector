# Security

The PHION connector does not need wallet recovery phrases, private keys,
passwords or API credentials. Never place those values in a PHION request or
repository issue.

Installation connects only to the public PHION decision service. It does not
authorize spending. Review the displayed price and terms before approving any
paid action.

Security concerns should be reported privately through PHION's verified public
profile or official website channel, not through a public issue containing
sensitive details.
