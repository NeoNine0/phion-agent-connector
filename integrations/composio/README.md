# PHION for Composio

Add PHION's public decision surface as a no-auth Custom MCP toolkit in a
Composio project:

`https://phion.systems/mcp/decision`

The verified installation synchronizes seven bounded tools. Confirm that
`CUSTOM_PHION_PHION_RESOLVE` is present, then use it in `PREFLIGHT` mode before
considering any paid execution.

Installation does not grant wallet access, payment authority or credentials.
Keep payment approval separate and preserve PHION's abstentions when no route
satisfies the requested constraints.

and a successful zero-payment `phion_resolve` invocation. This is not a claim
