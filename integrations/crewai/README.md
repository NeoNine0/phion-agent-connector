# PHION for CrewAI

Use CrewAI's `MCPServerHTTP` or `MCPServerAdapter` with
`https://phion.systems/mcp/decision`. Begin with `phion_resolve` in
`PREFLIGHT` mode and review the route, price and evidence contract before any
paid action.

Run `validate_phion.py` after installing `requirements.txt` for a model-free,
payment-free connection test. Installation never grants wallet credentials or
automatic spending authority.
