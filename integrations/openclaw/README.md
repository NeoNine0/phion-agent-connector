# PHION Pre-Resolution for OpenClaw

Optional `before_prompt_build` plugin. It classifies a small fixed set of external capabilities locally and sends only the generic capability label to PHION. Local work and visible provider mandates do no network work. The plugin never pays, signs, executes, narrows tools or stores prompts.

Build compatibility was validated against OpenClaw 2026.9.8. ClawHub publication remains unclaimed until its external page and install path are verified.
